# NillaNinja Business Dojo

NillaNinja Business Dojo is a long-term SaaS platform designed to help owner-operated and small businesses understand how they operate, identify practical opportunities, and receive clear, actionable recommendations.

## Version 0.1 Goal

Build a completely browser-based MVP that guides a business owner through:

1. Welcome
2. Business Profile
3. Business Assessment
4. Business Snapshot Report
5. Report Export

## Core Philosophy

- Build for owner-operated businesses with approximately 1–20 employees.
- Explain everything in plain English.
- Recommend solutions rather than only identifying problems.
- Treat AI as one useful tool, not the entire product.
- Make every recommendation actionable.
- Explain why each recommendation matters.
- Explain the likely business impact.
- Explain how difficult the recommendation will be to implement.

## Development Rules

- Mac Terminal workflow
- One clear step at a time
- Plain HTML, CSS, and Vanilla JavaScript
- No React
- No frameworks
- No npm
- No build tools
- Lightweight and understandable code
- Git checkpoints before major milestones
- Localhost testing before deployment

## Version 0.1 Technology

- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage
- No backend
- No accounts
- No external APIs
